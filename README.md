# Shore photography template

A fictional Squarespace-style portfolio built in ChatGPT Sites.

Live Site: https://shore-photography-template.codefolio-work.chatgpt.site

## Preview

Serve the `dist` directory with any static web server. No build or dependency installation is needed.

## Features

- Responsive portfolio with downloaded sample images.
- Water and land filters and full-size photograph dialogs.
- Right-side navigation drawer with independent scrolling and keyboard support.
- Enquiry preview only; nothing is submitted or saved.
- Actual saved Johnny UI SVGs and profile.
- Plain visible numbering: 1, 2, 3.

See WEBSITE_DESIGN_BASELINE.md and DESIGN_DECISIONS.md for rules and verification limits. This is a visual mockup, not an installable Squarespace theme. Image source URLs are recorded in DESIGN_DECISIONS.md.
